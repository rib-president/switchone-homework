# fx-order-api

실시간 환율 기반 외환 주문 시스템

외부 환율 API를 연동하여 실시간 환율(USD, JPY, CNY, EUR)을 수집하고, 이를 바탕으로 사용자의 외화 매수/매도 주문을 처리하는 백엔드 서버 시스템입니다.

## 기술 스택
* **Language:** Java 17
* **Framework:** Spring Boot 3.x
* **Database:** H2 (In-Memory)

## 주요 기능
* **환율 스케줄러:** 1분 단위로 4개 주요 통화의 최신 환율을 수집하고 DB에 이력을 저장합니다.
* **실시간 환율 조회:** 전체 통화 및 특정 통화의 매매기준율, 전신환 매입율, 전신환 매도율을 조회합니다.
* **외화 주문 처리:** 현재 환율을 기준으로 원화(KRW) 환산 금액을 계산하여 주문을 처리하고 내역을 저장합니다.
* **주문 내역 조회:** 성공적으로 처리된 과거 외환 주문 이력을 제공합니다.

## API 명세

| Method | Endpoint | Description |
|---|---|---|
| GET | `/exchange-rate/latest` | 전체 통화 최신 환율 조회 |
| GET | `/exchange-rate/latest/{currency}` | 특정 통화 최신 환율 상세 조회 |
| POST | `/order` | 외화 주문 |
| GET | `/order/list` | 전체 주문 내역 조회 |

## 프로젝트 실행 방법
1. 프로젝트를 클론합니다.
2. 루트 디렉토리에서 IDE(IntelliJ 등)를 통해 애플리케이션을 실행합니다.
3. 데이터베이스는 H2 In-Memory를 사용하므로 별도의 DB 설치 및 세팅이 필요하지 않습니다.
